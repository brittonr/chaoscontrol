## Decision

WithLastValueBy is a new typed variant, leaving WithLastValue's public contract unchanged. Both branches use the same key_field selector: canonical kind/text/process/source_kind precedence, otherwise derived strings. Keys compare exact UTF-8 strings; no numeric/JSON coercion or normalization. Missing is not an empty key and does not match missing. A present empty string is a valid explicit key. Users must project custom service keys independently on both branches. Keys do not establish causal or VM/history identity.

Share the existing annotation implementation. Represent the borrowed output/value/key/window selection in a small private selection record, avoiding an eight-argument function and all new per-row key allocations. Evaluate and admit both branches regardless of empty candidates/zero window. Charge normal child work plus every materialized candidate and witness before deduplication. Admit all original witnesses; canonical-sort and deduplicate source positions first so the first projection wins even if duplicates project different keys. For the keyed variant, order witnesses in place by selected key then canonical event order. Binary-search the (key, tick) boundary for each present candidate key, inspect only the nearest matching earlier event, and check the inclusive tick-distance bound. A preceding different key is never eligible, even if its tick is newer. Missing nearest selected values do not fall back to older same-key values. Resolve the original key before overwriting an aliased output. Remove stale output when undefined, retaining all other projections and canonical evidence. Admit generated rows immediately, preserving unhideable field/byte capacity errors.

Keep unkeyed sorting/selection behavior and all existing regressions. No Cartesian product, key map, copied key strings, tick array or candidate-vector clone. Structural/scan/work/derived/result/prefix limits, moment reconciliation and full query/source/result receipt binding apply. Both names plus the key name and both child queries must validate on empty sources. Old variants/schemas remain unchanged; new queries require upgraded readers.

The hidden-witness regression exposed an existing Union gap: a later invalid projected row could be dropped as a duplicate before the annotation helper saw it. Admit every Union row before source-position deduplication, matching DistinctByTick. This is shared intake enforcement, not a keyed-operator special case; valid legacy results are unchanged. The regression retains this bounded rejection path.
