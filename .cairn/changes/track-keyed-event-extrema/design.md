## Decision

Add RunningMinBy/RunningMaxBy alongside unchanged RunningMin/RunningMax. Use one private extrema_rows engine, with borrowed selection names, optional key and minimum/maximum choice. Reuse the RunningSumBy in-place grouping convention: charge/admit every child row before canonical stable sorting and source-position deduplication; only then sort unique rows by exact key and canonical order when needed. Resolve each group's boundary/presence before modifying output so aliases cannot regroup rows. Unkeyed operation has one present group. No key map, copied keys, prefix copies or extra event collection. Restore canonical output order after keyed evaluation.

Each group starts without an extremum, not at zero or infinity. Every unique row evaluates its predicate against original values; matching rows parse a complete finite JSON number using existing canonical-name lookup even when the key is absent. Present groups select by strict binary64 comparison, preserving the earliest equal value including signed zero. Nonmatching operands remain unread. Missing groups never select extrema; missing keys and pre-first-match rows remove stale output, while canonical evidence and other projections remain unchanged. Reuse output string storage/JSON number formatting and admit each generated row immediately. Names, predicate and input validate on empty sources; all normal predicate short circuit, structure/scan/work/derived/result/prefix/moment and receipt rules apply. Existing unkeyed behavior must not change.

## Verification

Capture baseline and exported references before source changes; scoped Cairn admission first. New regression must fail for unsupported variant before implementation. Behavioral coverage: independent per-key extrema via pairwise prefix oracle, interleaving/ties/permutations/tick boundaries, no-match and missing/empty/Unicode keys, negative-only values, aliases and first duplicate projections, signed-zero/rounding/underflow, invalid matching and skipped operands including absent keys, canonical selectors, JSON projection/downstream composition, empty/name/predicate/child admission, intermediate/generated capacity, shared limits/moments and receipts. Exercise the actual query-events query/validate interface with full expected rows, negative evaluation cases without artifacts, and query/operator/key/value/predicate/source/result drift. Run replay suite, Clippy, workspace compilation, formatting and scope/evidence checks, synchronize accepted requirement, commit/push owned changes only.

## Boundaries

Equal keys do not prove VM/history coherence. This implements bounded retained-input typed extrema, not Antithesis multiverse lineage or general fold parity. Regression tests and documented CLI are repeatable local query evidence; no VM/campaign/replay claim.
